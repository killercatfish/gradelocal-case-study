# GradeLocal: Product Case Study

A one-page case study of GradeLocal, an AI feedback assistant for teachers that I designed and built, demonstrated with synthetic student data. It is designed to run entirely on local hardware, so student work never reaches a cloud AI, and the teacher approves every word before a student sees it.

**Read it here, with the 1-minute demo video:** https://killercatfish.github.io/gradelocal-case-study/

- [PDF version](GradeLocal_Case_Study.pdf), for printing or attaching
- The demo uses a made-up worksheet, answer key and quiz: synthetic data only
